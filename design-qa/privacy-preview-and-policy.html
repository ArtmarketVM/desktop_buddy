What sumi records

While tracking is on and inside your working hours, sumi notes the app in front, its window title and how long you were active or idle. This is how it knows what counted toward a goal. It is saved in a local database that is not encrypted, so treat the Mac's own protection as the lock.

sumi never takes screenshots, never reads what you type, and skips password and editing fields when a feature looks at visible text.

What leaves your computer

Only when you use an AI feature, and only to the provider whose key you entered. Each feature sends the minimum it needs:

FeatureGoes toWhat is sent
Progress check-inNebiusYour goal and up to 10 recent windows: app, title, active and idle seconds
Suggested resourcesNebius, then TavilyYour goal and up to 5 window titles to form a search; Tavily sees only the search
Coach chatNebiusYour message, the goal, and a few relevant memories if Memory is on
Manual searchTavilyThe query you typed

Providers keep requests under their own policies; deleting data in sumi does not delete it there.

Your keys

API keys are stored in the macOS keychain and sent only to the provider they belong to, as authentication.

Memory

Memory keeps a few facts you tell the coach so it can remember them next time. It never stores screen text. Turn it off in Settings · Memory to stop saving and recalling; existing facts stay until you clear them.

Deleting

Settings · Privacy lets you keep history for a fixed time or clear it all at once. Clearing removes activity, daily app time, suggestions, ratings and finished goals. Your active goal, settings and keys stay.

Changes

When this page changes, the date at the top changes with it. The current version is always the one linked from Settings.
