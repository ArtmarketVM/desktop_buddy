# Desktop Buddy 0.28.0

- Saved checkpoints are now quiet controls at the right of each goal title. Open one to see where you stopped, the next action, waiting information and Park/Resume controls. Dates and long summaries no longer occupy a separate row. Checkpoints preserve context; they do not prove that work is complete.
- Goal action menus are exclusive. Opening another menu closes the previous one; an outside click, focus change or Escape also closes it. Menus appear beside the trigger, leaving neighboring goals' action buttons reachable, and stay within the window.
- A compact AI services block above Settings explains Nebius, the configured NVIDIA Nemotron model and Tavily. Hover or focus a name for details. Green means recently verified authentication/model-list access, red means unavailable or unconfigured, and gray means unchecked, expired or simulated. A manual refresh checks provider metadata without generation, search queries, goals or memory. Checks time out after 10 seconds, are throttled and expire after 15 minutes. Reading status is local and does not make provider requests. Generation, billing and search success are not inferred from a connection check.
- Today has visible drag grips, immediate pointer pickup, edge scrolling and a destination indicator. Keyboard users can pick up with Space, move with arrow keys and drop with Space; Escape cancels. Rust validates and persists the resulting order. Goals outside the visible lane keep their positions. Reordering does not complete goals, change Today membership or select a focus goal.

The common release includes Windows x64 and Mac Apple Silicon (macOS 14.5+). Persistent Mac app signing and trusted updater keys are unchanged. No database migration is required, and goals, chats, memory and provider credentials are retained.
