# Desktop Buddy 0.48.0

## A calmer start with Sumi

- Get through three short welcome cards without entering API keys. Choose With tracking to notice work, time spent and finished steps, or Without tracking to check off steps yourself.
- On macOS, choosing tracking opens Accessibility settings only when access is missing. Granted access stays out of the way; Windows needs no extra permission dialog for ordinary app and time tracking.
- Start with an expanded Install and start using Sumi goal: install the app, create a goal, and explore My progress. Installation receives a fixed five-minute onboarding credit, shown once on the goal and in Progress.
- Three welcome bubbles guide each step. Cross it off marks installation and opens goal entry; Cross off & view progress marks the first goal and opens Progress; Finish setup completes the last step and returns to Today. Goal suggestions are available as you type when AI is connected.
- Later postpones a setup bubble for ten minutes, including after restart. Regular daily-planning prompts wait while setup is active.

## AI defaults for new profiles

- AI assistance, goal sharing, web research, activity matching, dictated-text correction, screenshot support and verified automatic completion start enabled for new profiles. Existing saved choices are preserved.
- Without tracking keeps activity observation off. Operating-system permissions and connected provider credentials still apply. All controls remain available in Settings; keys are never included in the app bundle.
- Updated privacy and voice documentation explains the new defaults and what each feature shares. Product defaults do not create personal-memory records.

## Platforms and preservation

- Windows x64 and Apple Silicon macOS 14.5+. The Mac app uses the existing internal signing identity and immutable credential helper; Apple notarization is not provided.
- Existing goals, provider connections, saved preferences and updater trust are retained. Earlier installers are not replaced. The latest MIT and bundled-font license notices are included.
