# Desktop Buddy 0.47.0

## Personalized goal suggestions

- Today and All goals now suggest new goal titles as you type, starting with a single character and refreshing after a short pause, like step suggestions.
- Suggestions use your saved goals and steps, selected work role, and permitted personal facts and preferences. Exact saved titles keep their existing search behavior.
- Use a suggestion with a click, arrows and Enter, or Tab to put it into the field for editing. You can always add your own wording, including when AI is unavailable. Typing alone never creates a goal.
- Outdated responses are discarded as the text changes. Completion requests no longer trigger unnecessary workspace refreshes, and clicking Create uses the title shown even when another saved goal is highlighted.

## Follow your computer's appearance

- Sumi follows the computer's light or dark appearance at startup and while running. Automatic mode is enabled by default for existing and new profiles.
- The sidebar theme button still provides a manual override. Re-enable automatic mode in Settings → General → Use system appearance.
- Workspace and companion windows share the appearance preference, and native window/tray icons update with the theme.

## Platforms and privacy

For Windows x64 and Apple Silicon macOS 14.5 or later. Signing identities, updater verification and existing update channels are preserved.

Goal autocomplete respects AI, goal-sharing and Memory controls. It does not send screen content or raw chat history, and it does not search the web. Suggestions remain editable and can need review. The privacy policy now describes this feature's data sharing.
