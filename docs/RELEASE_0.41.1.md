# Desktop Buddy 0.41.1

## A stationary companion with separate cards

- Keep the mascot in a fixed transparent window while chat and reminder cards use a separate window.
- Prefer cards above the mascot, with left, right and below placement when needed. Respect monitor work areas and scaling without moving the mascot.
- Prepare popup content before showing its native window; retain transparent margins and painted-shape click-through.
- Fit short reminders to their text and buttons without a scrollbar. Long reminder details open in chat.
- Show background reminders without acquiring keyboard focus.
- Keep the chat composer reachable with internal scrolling, and preserve the selected side while content changes.
- Preserve mascot-only reminders: no native notification plugin, permission request or system banner delivery.

Supported installers: Windows x64 and Apple Silicon macOS 14.5+. Native visual and multi-monitor checks are reported separately from automated geometry checks.
