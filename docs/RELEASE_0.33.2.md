# Desktop Buddy 0.33.2

Dark mode now uses neutral charcoal backgrounds and gray surfaces, borders and secondary text instead of green-tinted surfaces. The tinted grain texture is disabled in dark mode.

Green remains an accent for selection, actions and successful service status. Red connection errors stay visible. Light mode and the selected companion color are unchanged.

The shared theme applies to Windows x64 and Apple Silicon macOS 14.5+. Existing signing identities, credential handling and updater trust are unchanged.
