# Desktop Buddy 0.28.1

- The app now uses the sumi site design: Shippori Mincho for headings and the brand, Zen Maru Gothic for text, the moss-green and paper palette in light and dark themes, pill buttons and a subtle paper grain.
- The companion is the square kaku-mochi mascot from the site, with sleepy, alert and happy eyes for its states. Companion colors are Matcha, Mist and Cloud; a previously saved red, yellow or blue color migrates to the nearest new one.

This patch release includes Windows x64 and Mac Apple Silicon (macOS 14.5+). The persistent internal macOS signing identity, Tauri updater verification and all trusted updater keys are unchanged. No database migrations or changes to goals, activity, memory or provider keys are included.
