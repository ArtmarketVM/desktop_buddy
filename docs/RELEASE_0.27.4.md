# Desktop Buddy 0.27.4

- The sidebar toggle now uses a lightweight double-chevron icon: left to collapse, right to expand. The permanent background, border and stacked Hide/Menu labels have been removed.
- A subtle neutral background appears on hover, with a visible keyboard focus indicator. The accessible action label, shortcut, saved sidebar preference and fixed 44 × 44 click target remain available. The button stays in the same position when the sidebar changes width.

This common patch release includes Windows x64 and Mac Apple Silicon (macOS 14.5+). The persistent internal macOS signing identity introduced in 0.27.3, Tauri updater verification and all trusted updater keys are unchanged. No database migrations or changes to goals, activity, memory or provider keys are included.
