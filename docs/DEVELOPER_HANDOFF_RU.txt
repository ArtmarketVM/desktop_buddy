Desktop Buddy — памятка второму разработчику
Версия 0.12.0 • 2 октября 2026

ЧТО ДОБАВИЛОСЬ ПОСЛЕ 0.10.0

• Выбор роли: бесконечная карусель из девяти карточек со спокойными векторными иллюстрациями. Прокрутка стрелками, колёсиком и тачпадом в обе стороны. Девятая роль Other позволяет вписать любую профессию или занятие. Для любой роли можно указать до 20 приложений.
• Три цвета персонажа: красный, жёлтый, синий. Светлая и тёмная темы с согласованными иконками.
• Focus: упрощённый список шагов с автоматическим сохранением. Дополнительные действия спрятаны в раскрывающиеся блоки. Время активности показывается в минутах/часах и не означает процент выполнения цели. Resources переименован в Discover.
• Персонаж не прыгает, остаётся доступным при паузе трекинга и закрытии основного окна. Переключатель Show on desktop управляет только персонажем на рабочем столе; картинка внутри приложения сохраняется. Управление также доступно в трее.
• Настройки: список установленных Windows-приложений и редактируемые категории для текущей цели. Профиль открывается отдельно. Локальный выход/повторная настройка сохраняет цели, историю и ключи. Поля ключей перенесены в расширенные настройки подключений.
• Share an idea открыт сразу. Без сервера создаётся черновик письма на artmarket.vm@gmail.com; пользователь отправляет его сам.
• Подготовлен закрытый сервис Supabase: обратная связь, подтверждение email для рассылок, отдельное согласие и подтверждение для статистики email + роль + указанные приложения. Статистика не подписывает на рассылку. Сервер пока НЕ развёрнут: данные остаются локальными. Введённые приложения не создают правила трекинга автоматически.

КАК ОБНОВИТЬ УСТАНОВЛЕННОЕ ПРИЛОЖЕНИЕ

В версии 0.10.0 или новее: Updates → Check for updates → Update & restart.
Либо скачать Windows x64-установщик из релиза:
https://github.com/ArtmarketVM/desktop_buddy/releases/tag/v0.12.0
Завершить Buddy через меню в трее и установить поверх прежней версии в ту же папку. Цели, настройки и сохранённые ключи остаются на ПК. Ярлык запускает обновлённое приложение.

КАК ОБНОВИТЬ ИСХОДНИКИ ДЛЯ РАЗРАБОТКИ

Сначала сохранить свои незакоммиченные изменения в своей ветке. Из папки проекта выполнить:

git status
git switch main
git pull --ff-only origin main
npm ci

Если .env ещё нет, скопировать .env.example в .env и вписать СВОИ ключи. Запуск Windows-приложения: ./scripts/dev.ps1
Проверки: ./scripts/dev.ps1 -Task test
Нужны Node.js 22+, Rust/MSVC, Visual Studio C++ Build Tools с Windows SDK и WebView2. npm run dev запускает только браузерный предпросмотр.

ВАЖНО

git pull обновляет код, но не установленный exe: для него нужен установщик или встроенное обновление. .env, пользовательские базы и закрытый ключ подписи не публикуются. Ключ подписи официальных релизов остаётся только на ПК владельца. DEMO_MODE симулирует активность; AI_MOCK отдельно включает тестовые ответы AI.

Подробности: docs/CONTACT_SERVICE.md — подключение сервера; docs/BUDDY_ART_PROMPTS.md — промпты для персонажей; docs/VALIDATION.md — результаты проверок.
