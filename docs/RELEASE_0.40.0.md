# Desktop Buddy 0.40.0

## Understand and record your work

- Observe available foreground interface text across applications, with shared samples and bounded background requests.
- Optionally use temporary active-window screenshots to improve context understanding. Screenshots are off by default, require system access on macOS, and are never saved in history.
- Separately opt into automatic completion of existing goals and steps after current result evidence passes two checks. Undo remains available in the persistent daily work journal.
- Review work outside your plan: add ongoing work to Today, add verified completed work, skip it, or discuss it in chat. New goals are never created silently.
- View a meaningful work journal in Progress, separate from raw activity and Personal Memory. Daily continuity includes recorded results without treating time spent as completion.
- Add, inspect, correct and forget personal knowledge. Repeated task patterns require evidence and user review before influencing suggestions.
- Preserve the previous lane's window when automatically parking work during a goal switch.
- Inspect observation capabilities, screenshot status and request budgets in Personal AI Engine.

## Privacy and performance

Screenshot use and automatic completion are separate settings and default to off. Existing exclusions, privacy checks, tracking pause and stale-response validation apply. Quiet mode suppresses interruptions while permitted observation can continue. Images alone never authorize completion. Native interface coverage varies by application; hidden conversations and closed tabs are unavailable.

Background work uses a lightweight current-work snapshot instead of rebuilding weekly Progress analytics. Observation requests share an hourly budget and one background provider lock. Model judgments remain fallible; receipt checks and Undo reduce risk but do not guarantee perfect classification.

Supported installers: Windows x64 and Apple Silicon macOS 14.5+. Internal macOS signing is not Apple notarization.
