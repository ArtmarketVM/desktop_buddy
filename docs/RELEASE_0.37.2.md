# Desktop Buddy 0.37.2

## Goal matching suggestions

- Keep automatic assignment at confidence 0.8 or higher.
- Ask “Working on <goal title>?” for confidence 0.6 to below 0.8, with Yes, No and Not now choices.
- Yes uses the existing explicit-focus path and adds a saved goal to Today when needed.
- No suppresses that goal/app/domain suggestion for 24 hours, including across restarts.
- Not now pauses suggestions for ten minutes; low-confidence results remain silent.
- Preserve the 60-second AI stability gate and 90-second request cooldown.
- Include rejection records in existing history retention, history deletion, personal memory deletion and goal deletion.

Includes the preceding locally installed 0.37.1 chat, connection recovery and matching context improvements. This is a locally validated Apple Silicon macOS 14.5+ build; Windows installation and a joint GitHub release have not been published for 0.37.2.
