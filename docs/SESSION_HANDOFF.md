# Desktop Buddy session handoff

## Published 0.48.0 — 27 October 2026

- [Release 0.48.0](https://github.com/ArtmarketVM/desktop_buddy/releases/tag/v0.48.0) is public for **Windows x64 and Apple Silicon macOS 14.5+**. Release source **97e00d5bad95274c10125e223b3982f24b78be89**, tag `v0.48.0`. All five product manifests use 0.48.0. [Release notes](RELEASE_0.48.0.md) describe the final behavior; this handoff update is documentation only and needs no installer rebuild/version bump.
- Ships three short onboarding cards without API-key entry, a compact With tracking / Without tracking choice, minimal missing-access guidance, and the owner-approved option A welcome bubbles. Installation gets a fixed five-minute credit once. Cross it off confirms installation and focuses goal entry; Cross off & view progress confirms goal creation and opens My progress; Finish setup confirms the visit, completes the setup goal and returns to Today. Later snoozes ten minutes across restart. Regular launch-planning prompts wait while setup is active and for the already-planned finishing day; deadlines keep their normal path.
- New databases enable AI assistance, goal sharing, web research, activity matching, voice text cleanup, screenshot support, verified automatic completion and existing Memory controls. Existing saved choices and older missing-field defaults survive. Without tracking keeps activity observation off. Provider credentials and OS permissions remain independent. Initial defaults do not create personal-memory records.
