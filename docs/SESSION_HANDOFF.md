# Desktop Buddy session handoff

## Published 0.48.1 — 28 October 2026

- [Release 0.48.1](https://github.com/ArtmarketVM/desktop_buddy/releases/tag/v0.48.1) is public for **Windows x64 and Apple Silicon macOS 14.5+**. Source **7447369c069f506bb995ae72853fa77f1c633203**, tag `v0.48.1`. All five manifests use 0.48.1. This receipt is documentation only; do not bump/rebuild.
- Ships a shared **20-second minimum interval** for foreground capture, semantic observation and Accessibility text-cache refresh. The rolling-hour budget remains **120 background disclosures**, with three verification slots reserved from primary sampling. Busy workers, latency, unchanged evidence and privacy gates can delay/skip checks. Existing opt-outs survive; screenshots off still means no screenshots. Independent verification, Undo and the two-minute sealed-result lease remain intact.
- [Release notes](RELEASE_0.48.1.md) state the limits. The broader [completion reliability plan](COMPLETION_RELIABILITY_PLAN.md) remains proposed apart from this cadence adjustment: persistent diagnostics, the full image-generation workflow and delivery improvements are not implemented.
